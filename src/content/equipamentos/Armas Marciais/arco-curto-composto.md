# Arco Curto Composto

**Custo** 75 PO  **Peso** 2lbs
**Dano** 1d6  **Crítico** x3  **Tipo** Perfurante
**Categoria** Distância  **Grupo** Arcos
**Alcance** 21 Metros (Projétil)
**Especial** Veja o texto

Você precisa de pelo menos duas mãos para usar um arco, independentemente de seu tamanho. É possível usar um arco curto composto enquanto estiver montado.

Todos os arcos compostos são fabricados com um valor específico de Força (isto é, cada um exige um modificador mínimo de Força para ser usado com proficiência). 

Se o seu bônus de Força for menor que o valor de Força do arco curto composto, você não consegue usá-lo de forma eficaz e sofre uma penalidade de –2 nas jogadas de ataque com ele. 

O arco curto composto padrão exige um modificador de Força de +0 ou maior para ser usado com proficiência. Um arco curto composto pode ser fabricado com um valor de Força mais alto para aproveitar um atributo de Força acima da média; essa característica permite adicionar seu bônus de Força às jogadas de dano, até o bônus máximo indicado para o arco. 

Cada ponto de bônus de Força concedido pelo arco aumenta seu custo em 75 po. Se você tiver uma penalidade por Força baixa, aplique-a às jogadas de dano ao usar um arco curto composto.

Para fins de Proficiência com Armas, Foco em Arma e talentos semelhantes, um arco curto composto é tratado como se fosse um arco curto.
