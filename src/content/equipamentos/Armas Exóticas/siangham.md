# Siangham

**Custo** 3 PO  **Peso** 1lb
**Dano** 1d6  **Crítico** x2  **Tipo** Perfurante
**Categoria** Leve  **Grupo** Monge
**Alcance** -
**Especial** Monge

Esta arma consiste em uma haste curta empunhada com a mão, equipada com uma ponta afiada para perfurar inimigos. Ela se assemelha a uma flecha (bem mais resistente), com uma empunhadura projetada especificamente para o combate corpo a corpo.
