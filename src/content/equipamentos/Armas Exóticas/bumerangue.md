# Bumerangue

**Custo** 3 PO  **Peso** 1,5kg
**Dano** 1d6  **Crítico** x2  **Tipo** Concussão
**Categoria** Distância  **Grupo** Arremesso
**Alcance** 9 Metros (Arremesso)
**Especial** -

O bumerangue é principalmente uma ferramenta de caça, mas não é incomum que essas armas de arremesso versáteis sejam levadas para o campo de batalha. 

Um bumerangue é feito de madeira e é plano, com um cabo longo, uma curva pronunciada para frente e uma dobra afiada para trás na extremidade. Um bumerangue de retorna ao ponto de arremesso.
