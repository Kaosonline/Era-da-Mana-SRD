# Espada Bastarda

**Custo** 35 PO  **Peso** 6lbs
**Dano** 1d10  **Crítico** 19-20/x2  **Tipo** Cortante
**Categoria** Uma Mão  **Grupo** Lâminas Pesadas
**Alcance** -
**Especial** Veja o texto

Uma espada bastarda mede cerca de 1,2 metro de comprimento, sendo grande demais para ser usada com uma só mão sem treinamento especial; por isso, é considerada uma arma exótica. 

Um personagem pode usar uma espada bastarda com duas mãos como uma arma marcial.
