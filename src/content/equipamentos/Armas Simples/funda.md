# Funda

**Custo** 0  **Peso** 0
**Dano** 1d4  **Crítico** x2  **Tipo** Concussão
**Categoria** Distância  **Grupo** Arremesso
**Alcance** 15 Metros (Projétil)
**Especial** -

Uma funda é pouco mais que uma bolsa de couro presa a um par de cordas.

Seu modificador de Força se aplica às jogadas de dano ao usar uma funda, assim como acontece com armas de arremesso. Você pode disparar uma funda com apenas uma mão, mas não pode recarregá-la dessa forma.

Recarregar uma funda é uma ação de movimento que exige duas mãos e provoca ataques de oportunidade.

Você pode arremessar pedras comuns com uma funda, mas pedras não são tão densas nem tão bem arredondadas quanto projéteis apropriados. Assim, esse ataque causa dano como se a arma fosse projetada para uma criatura de uma categoria de tamanho menor que a sua e você sofre uma penalidade de –1 nas jogadas de ataque.
