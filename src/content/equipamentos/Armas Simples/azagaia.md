# Azagaia

**Custo** 1 PO  **Peso** 1kg
**Dano** 1d6  **Crítico** x2  **Tipo** Perfurante
**Categoria** Distância  **Grupo** Arremesso, Lanças
**Alcance** 9 Metros (Arremesso)
**Especial** -

Uma azagaia é uma lança leve projetada para arremesso.

Como a azagaia não foi feita para combate corpo a corpo, você é considerado não proficiente ao usá-la dessa forma e sofre uma penalidade de –4 nas jogadas de ataque se usar uma azagaia como arma corpo a corpo.
