# Besta Leve

**Custo** 35 PO  **Peso** 2kg
**Dano** 1d8  **Crítico** 19-20/x2  **Tipo** Perfurante
**Categoria** Distância  **Grupo** Bestas
**Alcance** 24 Metros (Projétil)
**Especial** -

Carregar uma besta leve é uma ação de movimento que provoca ataques de oportunidade.

Você arma uma besta leve puxando uma alavanca. Normalmente, operar uma besta leve exige as duas mãos. No entanto, você pode disparar, mas não carregar, uma besta leve com apenas uma mão, sofrendo uma penalidade de –2 nas jogadas de ataque. 

Você pode disparar uma besta leve com cada mão, mas sofre penalidades nas jogadas de ataque como se estivesse atacando com duas armas leves. Essa penalidade é cumulativa com a penalidade por disparar com apenas uma mão.
