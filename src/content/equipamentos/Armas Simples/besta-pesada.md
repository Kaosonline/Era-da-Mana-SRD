# Besta Pesada

**Custo** 50 PO  **Peso** 8lbs
**Dano** 1d10  **Crítico** 19-20/x2  **Tipo** Perfurante
**Categoria** Distância  **Grupo** Bestas
**Alcance** 36 Metros (Projétil)
**Especial** -

Carregar uma besta pesada é uma ação de rodada completa que provoca ataques de oportunidade.

Você arma uma besta pesada girando um pequeno guincho. Normalmente, operar uma besta pesada exige as duas mãos. No entanto, você pode disparar, mas não carregar, uma besta pesada com apenas uma mão, sofrendo uma penalidade de –4 nas jogadas de ataque. 

Você pode disparar uma besta pesada com cada mão, mas sofre penalidades nas jogadas de ataque como se estivesse atacando com duas armas de uma mão. Essa penalidade é cumulativa com a penalidade por disparar com apenas uma mão.
